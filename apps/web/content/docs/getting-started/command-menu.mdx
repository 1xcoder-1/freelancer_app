The command menu is the fastest way through the app. Press **Ctrl+K** (Cmd+K
on macOS) anywhere in the dashboard and start typing.

## What it can do

- **Jump**: open any client, project, invoice or settings page.
- **Run actions**: start or stop a timer, create an invoice, mark an invoice
  as paid, toggle a client as VIP.
- **Create**: new client, new project, new proposal, new expense.
- **Ask**: open Book AI with your query prefilled.

Results are ranked by how often you pick them. Frequent actions float to the
top, so after a few days the menu mostly matches your habits.

## Examples

| You type | You get |
| --- | --- |
| `acme` | The Acme client page, with projects and open invoices |
| `start` | The timer picker, filtered to active projects |
| `invoice` | Recent invoices plus the "create invoice" action |
| `overdue` | Every invoice currently marked Overdue |

## Keyboard details

- **Ctrl+K** opens and closes the menu.
- **Arrow keys** move the selection, **Enter** runs it.
- **Esc** backs out one level first, then closes.
- While the menu is open you can hold **Alt** and press a number to run the
  nth result.

<Callout type="tip">
  The desktop app adds a global quick capture with **Ctrl+Shift+F** that works
  even when Freelance Book is not focused. It is a different shortcut from the
  in-app command menu. See [Desktop and mobile](/docs/apps/desktop-and-mobile).
</Callout>

If an action exists in the UI but not in the menu, it is a bug worth
reporting. The goal is that the command menu covers every frequent action.
